## Platform
web

## Purpose and users
TBTI Affiliate Agent is a travel affiliate operations MVP. Operators curate products, import CSV order reports, inspect attribution, and review AI optimization proposals. The portfolio demo serves recruiters and engineers who need to inspect these workflows without an operations account.

## Confirmed scope
The user requested an operable, visitor-isolated, resettable sample workspace with fictional orders, plus behavior tests for deduplication, authorization, and AI approval. The user confirmed fixed sample AI suggestions; the demo makes no paid model calls. Operations storage uses Neon PostgreSQL. Operations administration retains its shared-key boundary; demo roles do not grant operations access.

## Constraints
Preserve the existing Chinese operations UI and data. New demo copy is English for portfolio review. No production database or partner account is used for verification. Synthetic figures are sample data. Production metrics, multi-user identity, and live provider correctness remain unverified.
