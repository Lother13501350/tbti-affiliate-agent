# Sample workspace

Scope: /demo and /api/demo. Mode: Operate. Audience: recruiters and engineers evaluating a full-stack product workflow.

The user confirmed a visitor-isolated, resettable sample workspace with fictional orders and fixed AI suggestions. Preserve the incumbent neutral system-font operations UI; new demo copy is English. This is a precise workflow extension, code-led, without a visual-world replacement.

The first viewport has a task header and role/reset controls above a wider import/report column and a narrower review queue. The sequence is report import, duplicate replay, status update, permission denial, and reviewed product mutation. The memorable action is approving a bounded boost and seeing the curation score and action receipt change.

The demo uses server-validated signed cookie state. Production data uses PostgreSQL; real SQL transactions and concurrency are tested separately in an exclusive local/CI database. No production database or paid AI calls are involved. Parallel browser tabs can overwrite the sample cookie; the demo is not a multi-user operations system.
